Агентные системы

      
Агентам не верят на слово

      
swarm-orchestrator — рой из моделей разных семейств. Цель раскладывается на задачи, каждый артефакт проходит кворум ревьюеров, а работа принимается только после реальной проверочной команды на машине. Рой уже писал код в двух моих проектах, в изолированных worktree и под ревью человека.

      

        
      


      

        

          
Рой → PR, не в main

          
Рой работает в изолированном git worktree на отдельной ветке. Перед мержем дифф читает человек. Команды, которые написала модель, без явного разрешения не выполняются.

        

        

          
LangGraph + interrupt()

          
AIkimat: письмо гражданину не уходит, пока человек не нажал approve. Граф останавливается и ждёт, решение пишется в журнал аудита.

        

        

          
Инструменты с уровнем риска

          
Запой: опасный вызов ждёт кнопку «Разрешить» в push-уведомлении. Red-team проверяет, выполнится ли заблокированный инструмент после отравленной страницы.

        

      

      
Честно про ограничения: бесплатный шлюз роя зависит от сети. Когда модели отдают 403 или 429, рой останавливается на застое и не выдаёт пустой результат за готовый.
